# Unity 2D ARPG 核心玩法原型
独立开发的 2D ARPG 客户端原型项目，专注战斗系统、角色养成、怪物 AI 与模块化架构实现。

## 项目信息
- 开发周期：2025.07 – 至今
- 开发引擎：Unity 2022 LTS
- 开发语言：C#
- 项目类型：独立求职 Demo


## 已实现功能
- **角色控制系统**：移动/攻击/受击/死亡全状态管理，基于FSM状态机实现
- **背包&装备系统**：UGUI搭建完整界面，支持物品堆叠/分类/装备/随机掉落（加权随机算法）
- **怪物AI系统**：FSM有限状态机实现巡逻/追击/攻击/受击/死亡完整行为逻辑
- **数据管理系统**：ScriptableObject配置数据 + Json异步存档（背包/装备数据持久化）
- **音效管理系统**：BGM/音效分离控制，混音器层级管理
- **UI框架系统**：BasePanel基类+UIManager统一管理，支持面板缓存/坐标自适应


## 技术亮点
- 采用模块化架构，代码结构清晰，便于扩展与维护
- 使用有限状态机实现稳定、低消耗的怪物 AI 逻辑
- 基于对象池实现UI格子复用，大幅减少GameObject频繁创建销毁带来的GC开销
- ScriptableObject 统一管理配置资源，降低耦合
- 基于单例模式实现全局管理器，规范项目调用流程
- 纯手写逻辑，无重型插件依赖，适合作为客户端基础框架
- 基于面向接口设计，通过IInteractable等接口统一交互行为

## 项目说明
本项目为求职展示 Demo，聚焦 ARPG 核心战斗与养成玩法实现，后续地图、存档、场景切换等功能正在持续迭代中。
