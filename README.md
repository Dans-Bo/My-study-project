# Unity ARPG 核心玩法原型
独立开发的 ARPG 客户端原型项目，专注战斗系统、角色养成、怪物 AI 与模块化架构实现。

## 项目信息
- 开发周期：2025.07 – 至今
- 开发引擎：Unity 2022 LTS
- 开发语言：C#
- 项目类型：独立求职 Demo
- 
## 已实现功能
- 角色控制系统：移动、攻击、受击、死亡状态逻辑
- 背包与装备系统：UGUI 背包界面、物品数据管理、装备属性绑定
- 怪物 AI 系统：基于有限状态机（FSM）实现巡逻、追击、攻击、死亡完整行为
- 音效管理系统：ScriptableObject 配置音效资源，支持 BGM / 音效分离音量控制
- UI 系统：主界面、角色面板、背包界面逻辑交互

## 技术亮点
- 采用模块化架构，代码结构清晰，便于扩展与维护
- 使用有限状态机实现稳定、低消耗的怪物 AI 逻辑
- ScriptableObject 统一管理配置资源，降低耦合
- 单例模式 + 全局管理器，规范项目调用流程
- 纯手写逻辑，无重型插件依赖，适合作为客户端基础框架

## 项目说明
本项目为求职展示 Demo，聚焦 ARPG 核心战斗与养成玩法实现，后续地图、存档、场景切换等功能正在持续迭代中。
